# بوابة المبيعات — GitHub Pages + Google Apps Script

- **الواجهة**: صفحات ثابتة على GitHub Pages (دائمة، بلا خادم).
- **الخلفية**: Google Apps Script داخل حسابك، يقرأ ويكتب في مجلد المشاريع في Drive ويدير المستخدمين.
- **ثلاث لغات**: العربية، الكوردية (سوراني)، الإنجليزية. يغيّرها الموظف من زر 🌐 أعلى الصفحة (وعلى شاشة الدخول)، ويتغير معها الاتجاه (RTL/LTR) وقالب رسالة واتساب.
- **قابل للتثبيت كتطبيق** (PWA) بزر عائم، وأزرار الرجوع تعمل داخل التطبيق.

```
index.html  app.js  i18n.js  style.css  config.js   ← الواجهة
share.html  share.js                                ← صفحة العميل (روابط المشاركة)
sw.js  manifest.webmanifest  icons/  favicon.svg     ← التثبيت كتطبيق والأيقونات
apps-script/Code.gs  appsscript.json                ← الخلفية (تُلصق في Apps Script)
test/                                               ← الاختبارات
```

## الجزء 1: الخلفية على Google (10 دقائق)

1. في Drive أنشئ مجلداً رئيسياً (مثلاً «المشاريع») وانسخ معرّفه من الرابط: `drive.google.com/drive/folders/`**`المعرّف`**
2. افتح [script.google.com](https://script.google.com) ← **New project**.
3. احذف المحتوى الموجود في `Code.gs` والصق محتوى `apps-script/Code.gs`.
4. من **Project Settings** (⚙️) فعّل **Show "appsscript.json" manifest file in editor**، ثم افتح `appsscript.json` في المحرر واستبدل محتواه بمحتوى الملف المرفق.
5. **Project Settings ← Script properties** أضف: `ROOT_FOLDER_ID` (المعرّف أو الرابط)، `ADMIN_PASSWORD`، واختيارياً `ADMIN_USERNAME` (الافتراضي `admin`).
6. اختر الدالة **`setup`** من القائمة أعلى المحرر واضغط **Run**، ووافق على الصلاحيات (Advanced ← Go to ... (unsafe) ← Allow؛ هذا سكربتك أنت). يُنشأ حساب المسؤول وتُحذف `ADMIN_PASSWORD` تلقائياً، ويُضبط المجلد الرئيسي على «Anyone with the link — Viewer» ليفتح العملاء الملفات.
7. **Deploy ← New deployment ← Web app** — Execute as: **Me**، Who has access: **Anyone** ← Deploy، وانسخ **Web app URL** (ينتهي بـ `/exec`).

> **بعد أي تعديل على `Code.gs`:** Deploy ← **Manage deployments** ← ✏️ ← Version: **New version** ← Deploy. وإلا يبقى الكود القديم يعمل (والواجهة الجديدة ستعرض «الخلفية قديمة»).

## الجزء 2: الواجهة على GitHub Pages

1. أنشئ مستودعاً **Public** (Pages على المستودعات الخاصة يحتاج خطة مدفوعة. لا أسرار في ملفات الواجهة).
2. ارفع كل الملفات (ما عدا `.env` إن وُجد). تأكد من رفع مجلد `icons` وملف `i18n.js` و`sw.js`.
3. عدّل `config.js`: ضع الرابط **داخل علامتي الاقتباس** في `API_URL`.
4. **Settings ← Pages ← Deploy from a branch ← `main` / `(root)`**. الرابط: `https://اسم-حسابك.github.io/اسم-المستودع/`.

## إرسال ملفات كبيرة (30 MB وأكثر)

بدون إعداد إضافي الحد 10 MB (حد Apps Script). لرفع الحد إلى **100 MB** (قابل للتعديل):

1. في [Google Cloud Console](https://console.cloud.google.com) (المشروع نفسه الذي فعّلت فيه Drive API) ← **APIs & Services ← Credentials ← Create credentials ← API key**.
2. اضغط على المفتاح ← **Application restrictions: Websites** وأضف `https://اسم-حسابك.github.io/*`، و**API restrictions: Restrict key ← Google Drive API** ← Save.
3. ضعه في `config.js`:
   ```js
   DRIVE_API_KEY: 'AIza...',
   MAX_DIRECT_MB: 100
   ```
المتصفح يحمّل الملف مباشرة من Drive (يحتاج أن يكون مشتركاً بالرابط، وهذا ما يفعله `setup`) ثم يمرّره إلى واتساب. إن فشل التحميل المباشر وكان الملف أقل من 10 MB استُخدم Apps Script، وإلا يُرسل رابط. المفتاح يظهر في الصفحة لكنه مقيّد بموقعك وبـ Drive API فقط. على الهواتف الضعيفة قد لا تحتمل الذاكرة ملفات ضخمة، فلا ترفع الحد كثيراً.

## نص في قسم المعلومات

في كل قسم من أقسام المعلومات الثلاثة زر **«إضافة نص»** (للمسؤول): عنوان اختياري + نص (حتى 4000 حرف). زر **«إرسال النص»** يرسله كرسالة واتساب عادية بلا رابط ولا قالب. عند إرسال القسم أو المشروع تُضمَّن النصوص في الرسالة. يُخزَّن النص كملف صغير `.note` داخل مجلد القسم في Drive.

## اللغات

- اللغة الأولى تُؤخذ من لغة المتصفح (ar/ckb/en) ثم يختار الموظف ما يريد وتُحفظ على جهازه.
- **قالب رسالة واتساب** (جملة الافتتاح وأسماء الأقسام) يتبع لغة الموظف الحالية. صفحة العميل تُفتح بلغة المرسل.
- المسؤول يعدّل **أسماء الموقع والأقسام وجملة الافتتاح لكل لغة** من «الإدارة ← أسماء وإعدادات الموقع» (أزرار اللغات أعلى الصفحة).
- أسماء المشاريع والملفات تبقى كما كتبتها.
- إعدادات النسخة السابقة تُرحَّل تلقائياً كإعدادات للعربية.

## التثبيت كتطبيق والأيقونة

- يظهر زر عائم **«تثبيت التطبيق»** على أندرويد/كروم. على iPhone يظهر الزر ويعرض خطوات «إضافة إلى الشاشة الرئيسية» (آبل لا تسمح بتثبيت برمجي). يمكن إخفاؤه ✕ لأسبوع، ولا يظهر داخل التطبيق المثبّت.
- **لاستبدال الأيقونة** ضع صورك بالأسماء نفسها داخل `icons/` (PNG بخلفية مصمتة):
  `icon-192.png` (192×192)، `icon-512.png` (512×512)، `icon-maskable-512.png` (512×512، الشعار داخل المنتصف الآمن ≈ 60%)، `apple-touch-icon.png` (180×180). وللتبويب `favicon.svg`.
- اسم التطبيق على الشاشة الرئيسية من `manifest.webmanifest` (`name` و`short_name`).
- بعد تغيير الأيقونة احذف التطبيق المثبّت وثبّته من جديد ليظهر الشعار الجديد.
- **زر الرجوع**: النوافذ (معاينة الملف، الإضافة...) تُغلق بزر الرجوع بدل مغادرة التطبيق، والرجوع من المشروع يعود للقائمة، وفي أعلى الصفحات زر رجوع مرئي (يفيد على iPhone).

## الاستخدام

- «مشروع جديد» (للمسؤول) ينشئ المجلد وأقسامه في Drive. الرفع من الموقع حتى 15 MB للملف؛ الفيديوهات الأكبر ارفعها في Drive داخل مجلد القسم ثم اضغط ⟳.
- بنية Drive: `المشاريع / اسم المشروع / info_ar · info_ku · info_en · videos · maps · location · prices` وصورة غلاف باسم `cover.jpg`.
- إيقاف حساب موظف يطرده فوراً. «إرسال: ملف/رابط» أعلى الصفحة يبدّل طريقة الإرسال.

## الصيانة (من محرر Apps Script)

| الدالة | متى |
|---|---|
| `resetAdminPassword()` | نسيت كلمة مرور المسؤول: ضع `ADMIN_USERNAME` و`ADMIN_PASSWORD` في الخصائص ثم شغّلها |
| `rotateSecret()` | يبطل كل الجلسات وروابط صفحات المشاركة المرسلة سابقاً |
| `setup()` | آمنة لإعادة التشغيل |

لرؤية سبب أي خطأ في الخادم أضف خاصية `DEBUG` بقيمة `1` وراجع **Executions**.

## حدود هذه المعمارية

- رفع من الموقع حتى 15 MB. الإرسال المباشر حتى 10 MB، أو حتى `MAX_DIRECT_MB` مع مفتاح API، وما فوق يُرسل رابطاً.
- ملفات Drive تُفتح بروابط «لكل من لديه الرابط»؛ من وصله رابط يبقى يفتحه بعد إيقاف حسابه.
- أول فتح لمشروع قد يستغرق 2–5 ثوانٍ، ثم يُخزَّن دقيقتين.
- كلمات المرور SHA-256 مكرر بملح، أضعف من scrypt.
- حساب Google Workspace قد يمنع نشر Web app لـ «Anyone».

## الاختبار

```
node test/backend.test.js     # الخلفية على بيئة Apps Script محاكاة
python3 test/e2e.py           # الواجهة في متصفح (يحتاج playwright)
```
المحاكاة لا تعوّض التجربة الحقيقية على Google: بعد النشر جرّب الدخول، ثم رفع ملف، ثم الإرسال إلى واتساب من هاتف.
